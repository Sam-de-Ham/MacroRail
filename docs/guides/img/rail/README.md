# Rail assembly views

Renders for the rail's assembly guide, in assembly order. They are made by
`hardware/render/` (see its README).

| File | Shows |
|---|---|
| `01-motor-end-block.png` | The motor-end block on its own: rod bosses, coupler passage, endstop tab. |
| `02-far-end-block.png` | The far-end block on its own. |
| `03-carriage.png` | The carriage plate on its own. |
| `04-floating-nut-carrier.png` | The floating nut carrier on its own. |
| `05-sample-platform.png` | The sample platform on its own. |
| `06-endstop-trigger.png` | The endstop trigger on its own. |
| `07-carriage-bearings.png` | The carriage upside down with the four SC8UU blocks bolted on. |
| `08-rods-end-blocks.png` | Both end blocks with the two guide rods and the carriage on them. |
| `09-motor-coupler.png` | The NEMA 17 on the motor-end block, its four screws and the coupler. |
| `10-lead-screw-nut-carrier.png` | The lead screw in the coupler, with the T8 nut on the floating carrier (carriage hidden). |
| `11-carriage-on-nut.png` | The carriage over the nut carrier, from low down, without the platform. |
| `12-sample-platform.png` | The sample platform bolted on the carriage. |
| `13-endstop.png` | The roller switch on the motor-end tab and the trigger with its adjustable screw. |
| `14-finished-front.png` | The finished rail from the front left (motor end). |
| `15-finished-back.png` | The finished rail from the back right (far end). |
