# Scan module assembly views

Renders for the scan module's assembly guide, in assembly order. They are made by
`hardware/render/` (see its README) from the Fusion model.

| File | Shows |
|---|---|
| `01-fork-bearing.png` | The fork with the 608 bearing pressed into the +Y upright. |
| `02-fork-tilt-motor-endstop.png` | The fork with the tilt motor and the endstop bracket, switch and bolts. |
| `03-cradle-yaw-motor.png` | The cradle upside down with the yaw motor and the KY-024 hall board under its floor. |
| `04-head-holder.png` | The yaw head with the specimen holder, centring screws, spring, pin clamp and pin. |
| `05-head-exploded.png` | The same parts exploded. |
| `06-cradle-in-fork.png` | The cradle hung in the fork on the tilt motor shaft and the tilt axle, with the flag bolt. |
| `07-tilt-endstop.png` | Close-up of the tilt endstop at tilt home (+90 deg): the flag bolt on the switch roller. |
| `08-on-carriage.png` | The module bolted on the rail carriage (sample platform removed). |
| `09-tilted.png` | The module tilted 50 deg and turned 35 deg. |
